# Week 9 - CIS, STIGs & Sysadmin Compliance
{: .no_toc }

---

## Topics

- CIS Controls and CIS Benchmarks: program safeguards versus product-specific configuration guidance; Level 1 and Level 2 profiles
- DISA STIGs: when a contract or system scope requires a particular STIG, and how to record versioned assessment evidence
- Baseline assessment and remediation with OpenSCAP, CIS-CAT, and STIG Viewer; verify changes and document exceptions
- Compliance examples across education (FERPA), healthcare (HIPAA), payment data (PCI DSS), financial institutions (GLBA), public-company reporting controls (SOX), personal data (GDPR), and defense contracts (CMMC)
- NIST SP 800-53 as a flexible security and privacy control catalog; distinguish control frameworks, laws, regulations, and contractual standards
- Translate applicable requirements into system-administration work: scope assets and data, manage access, harden and patch systems, retain logs, control changes, and produce audit evidence
- Applicability depends on the organization, data, system boundary, and contract; not every law specifies a server setting or applies to every organization

## Supplemental Readings & Videos

### Readings

- [CIS Benchmarks overview](https://www.cisecurity.org/cis-benchmarks-overview) — Purpose, profile levels, and how secure configuration guidance is developed.
- [NIST SP 800-70 Rev. 5: National Checklist Program](https://csrc.nist.gov/pubs/sp/800/70/r5/final) — Guidance on finding, using, and developing security configuration checklists.
- [FERPA and data security in education](https://studentprivacy.ed.gov/data-security-k-12-and-higher-education) — Education Department resources for protecting student data; FERPA does not prescribe a specific security control set.
- [HIPAA Security Rule](https://www.hhs.gov/hipaa/for-professionals/security/laws-regulations/index.html) — Administrative, physical, and technical safeguards for electronic protected health information.
- [PCI Data Security Standard](https://www.pcisecuritystandards.org/standards/pci-dss/) — PCI SSC standards and resources for payment-card data environments.
- [FTC Safeguards Rule](https://www.ftc.gov/legal-library/browse/rules/safeguards-rule) — Security program requirements for financial institutions covered by the FTC rule under GLBA.
- [SEC guidance on internal control over financial reporting](https://www.sec.gov/oca/controlfaq1004) — Context for SOX-related controls that can depend on systems supporting financial reporting.
- [General Data Protection Regulation](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng/) — The official EU regulation covering personal-data processing.
- [NIST SP 800-53 Rev. 5, Release 5.2.0](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final) — Security and privacy control catalog for information systems and organizations.
- [DoD CMMC program information](https://www.acq.osd.mil/asda/dpc/cp/cyber/cmmc.html) — Contract-driven requirements for protecting controlled unclassified information in the defense supply chain.

### Videos

- [MITRE ATT&CK Framework](https://www.mitre.org/news-insights/video/mitre-attckr-framework) — A concise overview for connecting a control decision to the threat behavior it is intended to address.
